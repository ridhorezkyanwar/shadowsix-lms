# Northflank deployment — archived / not used

Northflank was evaluated as a possible host for ShadowSix, but it was **not used for the live deployment**.

## Outcome — October 30, 2026

- Northflank onboarding completed and its GitHub integration showed `ridhorezkyanwar/shadowsix-lms` under Connected repositories.
- On the service-creation form, Northflank displayed **“Payment method required”** and requested a card before allowing service creation.
- The user chose a no-card, no-payment hosting route. No ShadowSix service, build, deployment, or public URL was created on Northflank.

The active website is [https://shadowsix.free.je/](https://shadowsix.free.je/) on InfinityFree. Its deployment and maintenance are documented in [INFINITYFREE_DEPLOYMENT.md](INFINITYFREE_DEPLOYMENT.md).

The repository still contains a Dockerfile and Docker Compose configuration for local development and compatible hosts. They are not used by the active InfinityFree deployment.
